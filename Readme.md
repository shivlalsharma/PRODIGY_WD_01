# Responsive Landing Page

This project features a responsive and interactive navigation menu that dynamically changes style when scrolled or when hovering over menu items. The menu is designed to remain fixed at the top of the page, ensuring accessibility and usability across all pages.

## Deployment

The project is live and accessible at the following link:  
[Responsive Landing Page Live Demo](https://fitlife03.netlify.app/)

## Features

- **Responsive Design**: The navigation menu adjusts seamlessly across various screen sizes, offering a smooth user experience on desktops, tablets, and mobile devices.
- **Fixed Position**: The menu remains visible at the top of the viewport, ensuring constant access to navigation links.
- **Scroll Interaction**: The background color or font style of the navigation menu dynamically changes when scrolling down the page.
- **Hover Effect**: Menu items highlight when hovered over, to enhance usability and interactivity.
- **Cross-Browser Support**: Compatible with modern browsers to ensure accessibility for a wide audience.

## Technologies Used

- **HTML**: For structuring the navigation menu and page content.
- **CSS**: For styling the navigation menu, including responsive design and hover effects.
- **JavaScript**: For adding interactivity, such as detecting scroll events and applying dynamic style changes.

## Installation

To run this project locally:

1. **Clone the Repository**  
   Clone the project repository to your local machine:
   ```bash
   git clone https://github.com/shivlalsharma/PRODIGY_WD_01.git
   ```

2. **Navigate to the Project Directory**  
   Change to the project directory:
   ```bash
   cd PRODIGY_WD_01
   ```

3. **Open in Browser**  
   Open the `index.html` file in your web browser:
   ```bash
   open index.html
   ```
   Alternatively, you can right-click the file and select "Open With" > "Browser."
